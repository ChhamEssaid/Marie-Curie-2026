## Retomar desde otro equipo

1. Abre o descarga esta carpeta desde GitHub. Para descargar el repositorio completo, usa **Code → Download ZIP**.
2. Lee `CURRENT_STATE.md` y abre el Word de `v9.4/`.
3. Si haces cambios, guarda una nueva versión para conservar este punto de partida; revisa también el PDF exportado.
4. Al continuar con otro asistente, indícale: «Lee STRAT_TRACE_2026-09-07/CURRENT_STATE.md y continúa desde la propuesta v9.4, respetando los periodos, las configuraciones y las limitaciones allí documentadas».

La v9.4 tiene diez páginas revisadas visualmente y fuentes incrustadas en el PDF. Esta carpeta reúne documentos de propuesta y continuidad; no contiene las series experimentales ni resultados nuevos de simulaciones.
